Basti bestätigt im selben Auftrag die Vercel-Kündigung. Erneute Abfrage: beattrack.app antwortet mit HTTP 200 vom Hetzner-Server; API-Health ist ebenfalls 200. GitHub meldet weiterhin den gespeicherten success-Status des Deployments vom 07.09.; dessen Vercel-URL liefert heute HTTP 302 zur Vercel-Anmeldung.
