 def _compute_radar(hc: list[float]) -> RadarFeatures:
     """Compute 5 radar categories from 44-dim handcrafted vector.
 
     Indices: MFCC mean [0:13], MFCC stdev [13:26], HPCP [26:38],
     spectral_centroid [38], spectral_rolloff [39], BPM [40],
     ZCR [41], average_loudness [42], danceability [43].
     """
     if len(hc) < 44:
         return RadarFeatures(timbre=0, harmony=0, rhythm=0, brightness=0, intensity=0)
 
     # Timbre: RMS of MFCC means (skip first = energy)
     mfcc = hc[1:13]
     timbre = math.sqrt(sum(x * x for x in mfcc) / len(mfcc))
 
     # Harmony: mean absolute HPCP
     hpcp = hc[26:38]
     harmony = sum(abs(x) for x in hpcp) / len(hpcp)
 
     # Rhythm: combine BPM (normalized to 0-1 range: 60-200) and danceability
     bpm_norm = max(0, min(1, (hc[40] - 60) / 140)) if hc[40] > 0 else 0
     dance = max(0, min(1, hc[43]))

## Was das ist

Automatisierte Pipeline fuer den YouTube-Kanal **Investors Club Global** (EN):
aktuelle Finanznachrichten werden zu animierten Premium-Erklaervideos. Output-
Kadenz: **1 Langvideo (~10 Min, 16:9) + 3 abgeleitete Shorts (9:16) pro Tag**,
24/7 automatisiert mit Auto-QA-Gate und Scheduled-Publish-Puffer.

USP-Formel jedes Langvideos: **News -> Erklaerung -> Mechanismus -> Auswirkung
-> Einordnung** (Was ist passiert? Warum? Warum wichtig? Welche Auswirkung?).

- **Eine Sprache: TypeScript/Node (>= 22).** Kein zweites Runtime hinzufuegen
  (Remotion ist React/TS — alles bleibt im TS-Stack). Aenderung nur nach
  ausdruecklicher Freigabe.

  `src/pipeline/ports.ts`; Adapter in `src/adapters/`. Der Kern (`src/domain/`)
