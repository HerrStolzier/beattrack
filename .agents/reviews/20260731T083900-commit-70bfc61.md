    Drop npm, corepack and yarn from the web runtime image
    
    The runner stage only ever executes `node apps/web/server.js`, but the
    node:22-alpine base ships a full npm tree that carries its own CVEs —
    currently CVE-2026-59873 in the bundled node-tar, for which no Node base
    image tag has picked up the fix yet. Removing the unused package managers
    takes the vulnerable code out of the deployed image and shrinks it.
    
    Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
